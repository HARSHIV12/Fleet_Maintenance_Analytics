# Fleet Maintenance & Vehicle Performance Analytics

## 📌 Project Overview

A logistics and transportation company wants to improve fleet efficiency, reduce maintenance and fuel costs, minimize vehicle downtime, and improve driver performance.

This project analyzes fleet data including trucks, drivers, trips, fuel purchases, maintenance records, routes, facilities, and vehicle utilization.

## 🎯 Business Problem

Management needs better visibility into:

- Vehicle utilization
- Maintenance costs
- Fuel consumption
- Vehicle downtime
- Trip performance
- Driver performance

### Business Question

**How can the company use fleet, maintenance, fuel, trip, and driver data to reduce operational costs, minimize vehicle downtime, improve fleet utilization, and enhance overall fleet performance?**
